# SGSITS Marketplace visual system

## Build
- Replace the current purple theme with a restrained crest-derived navy, gold, paper, and ink palette.
- Use Outfit for confident headings and Figtree for highly readable body text.
- Create an original SVG icon family for resources and navigation, plus highlight, margin-mark, sticker, and repeatable paper-pattern components.
- Add custom empty-state, upload-success, bookmark, and download visuals with lightweight reduced-motion-safe animation.
- Apply the system consistently to shared navigation, cards, filters, forms, and all existing pages without changing the app’s workflows.

## Technical details
- Keep all colors in semantic Tailwind v4 tokens in the global stylesheet.
- Keep SVG assets as reusable typed React components with accessible labels.
- Preserve existing TanStack routes, sample data, and frontend-only behavior.
- Verify the homepage, discovery, resource, upload, profile, saved, login, and signup views at desktop and mobile sizes.
