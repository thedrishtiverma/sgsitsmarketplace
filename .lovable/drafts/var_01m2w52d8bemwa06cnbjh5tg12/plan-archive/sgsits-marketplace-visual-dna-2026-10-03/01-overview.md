# SGSITS Marketplace visual DNA

## Build
- Turn the existing marks into one restrained visual grammar: signature highlighter, four margin marks, one custom resource-icon family, three sticker states, and four paper-derived patterns.
- Make the highlighter the strongest recurring signature across key headlines, section labels, resource cards, and success moments.
- Add a student-focused dark mode that feels like a late-night study desk, not a generic inverted interface, with a persistent light/dark toggle.
- Apply the system consistently across Home, Explore, Resource Details, Upload, Profile, Saved, Login, Signup, My Uploads, and the shared navigation and states.
- Preserve all current page behavior, filters, sample data, bookmarks, and upload simulation.

## Visual rules
- One expressive accent per section; decorative elements remain supporting details.
- Resource symbols share the same document silhouette and hand-drawn line weight.
- Margin marks appear only where they communicate emphasis or status.
- Patterns stay low-contrast and never compete with content.
- Motion is brief, functional, and disabled when reduced motion is requested.

## Verification
- Check every route at desktop and mobile sizes, including dark mode.
- Verify theme persistence, menu behavior, filters, bookmark interactions, and upload success.
- Confirm all pages build cleanly and remain readable in both themes.
